# INC-2026-095 – Mobile wallet top-up failures (PayBridge degradation)

## Summary
On 5 Oct 2026, PayBridge degraded again. The new circuit breaker opened correctly for interbank transfers, but the mobile wallet top-up service calls PayBridge through an older client that was not migrated. Wallet top-ups failed for 35 minutes.

## Impact
- ~6,200 failed wallet top-ups
- Other payment types were not affected (circuit breaker worked)

## Root Cause
Third-party gateway timeout without a circuit breaker on a service that was missed in the migration. There was no inventory of all services calling PayBridge.

## Resolution
Wallet top-up temporarily disabled with an in-app message until PayBridge recovered.

## Actions
- Build an inventory of all PayBridge consumers.
- Migrate the wallet top-up service to the shared resilient client.
