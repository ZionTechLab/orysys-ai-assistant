# INC-2026-034 – Month-end slowdown (connection pool exhausted)

## Summary
On 30 Apr 2026, payment processing slowed and then failed for 55 minutes during the month-end peak. This is a repeat of INC-2026-007.

## Impact
- Salary and supplier bulk payments delayed by up to 1 hour
- ~14,000 retail transfers failed

## Root Cause
The pool increase from INC-2026-007 was applied only to one of the two payment hub nodes. The second node still had 50 connections. Reconciliation queries had not yet moved to the read replica because the action was not tracked.

## Resolution
Pool configuration aligned across both nodes. Reconciliation jobs paused.

## Actions
- Manage pool settings in configuration as code, not manually per node.
- Track post-incident actions in the change board with owners and due dates.
- Post-incident review: MTG-002.
