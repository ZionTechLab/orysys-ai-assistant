# RB-007 – Access requests and password resets

## Password reset
1. Verify identity using the staff ID and a call-back to the registered mobile number.
2. Never reset a password based on an email request alone.
3. Force MFA re-registration after a reset if phishing is suspected.

## Access requests
- Requests are raised in the service portal and approved by the line manager.
- Access to production systems also needs approval from the system owner.
- Privileged access follows POL-008.
