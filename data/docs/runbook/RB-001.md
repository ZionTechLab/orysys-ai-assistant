# RB-001 – TLS certificate renewal

## When to use
- Certificate expiry alert (30, 14 or 7 days)
- Production outage caused by an expired certificate

## Steps – planned renewal
1. Find the certificate in the central certificate inventory.
2. Generate a CSR on the target host (never move private keys by email).
3. Submit the CSR to the internal CA or the card network portal.
4. Install the certificate in the staging environment and test the handshake.
5. Raise a standard change and install in production during the change window.
6. Update the expiry date in the inventory.

## Steps – emergency replacement
1. Declare SEV1 and open a bridge (RB-004).
2. Raise an emergency change; approval by the duty manager is enough.
3. Follow steps 2–4 above with the CA on-call contact.
4. Restart only the affected connector, not the whole switch.

## Verification
- `openssl s_client -connect <host>:443` shows the new expiry date.
- Test transaction approved in production.
