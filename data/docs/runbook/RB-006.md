# RB-006 – Mobile app release rollback

## When to use
Crash rate above 2% or a payment flow failing after a release.

## Steps
1. Turn off the new feature using its feature flag (preferred, takes effect in 1 minute).
2. If no flag exists, roll back the backend API to the previous version.
3. App store versions cannot be rolled back; publish a hotfix and force-update if needed.
4. Inform customer support and social media teams.
