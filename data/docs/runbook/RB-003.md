# RB-003 – PayBridge gateway degradation

## Symptoms
- PayBridge response time above 3 seconds.
- Circuit breaker state "OPEN" on the payments dashboard.

## Actions
1. Check the PayBridge status page and the payments on-call channel for maintenance notices.
2. If the circuit breaker is open, do **not** force it closed. It retries automatically every 30 seconds.
3. If any service is still calling PayBridge directly (old client), disable that feature with a customer message.
4. Disable automatic retries if PayBridge latency is above 10 seconds.
5. Inform customer support with the approved message.

## Approved customer message
"Transfers to other banks are temporarily delayed. Your money is safe and transfers will be processed automatically."
