# POL-001 – Information security policy

## Purpose
Protect customer and bank information from loss, misuse and unauthorised access.

## Rules
- All staff complete security awareness training every year.
- Customer data must not be stored on personal devices or personal cloud storage.
- Security incidents must be reported to the security team within 1 hour.
- Systems must use MFA for remote and privileged access.

## Owner
Chief Information Security Officer (CISO). Reviewed yearly.
