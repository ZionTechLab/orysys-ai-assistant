# INC-2026-078 – Month-end salary run failures

## Summary
On 31 Aug 2026, the third month-end incident this year. A new report query without an index held database connections for minutes. The pool (now 120 on both nodes) was exhausted within 20 minutes of the salary run starting.

## Impact
- 2 hours 10 minutes of degraded bulk payments
- ~110,000 salary credits delayed
- Regulator informed as per incident reporting requirements

## Root Cause
Connection pool exhaustion again. Contributing factors: a slow query released without performance review, reconciliation still on the primary database, and no alert on pool usage.

## Resolution
Query killed and index added. Report disabled until month-end completed.

## Actions
- Alert at 80% pool usage.
- Mandatory query performance review for payment hub releases.
- Complete move of reconciliation and reporting to the read replica before 30 Sep 2026.
