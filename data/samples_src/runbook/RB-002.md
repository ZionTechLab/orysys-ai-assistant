# RB-002 – Connection pool tuning and month-end readiness

## Symptoms
- Payment requests time out with "unable to acquire connection".
- Pool usage above 90% on the payment hub dashboard.

## Immediate actions
1. Check pool usage on **both** payment hub nodes.
2. Find long-running queries: sessions active more than 60 seconds.
3. Pause reconciliation and reporting jobs.
4. Kill blocking report queries after the duty manager approves.

## Month-end checklist (T-2 days)
- Confirm pool size is the same on all nodes (from config repository).
- Confirm reconciliation and reporting point to the read replica.
- Freeze non-urgent releases from T-2 to T+1.
- Load test at 5x normal daily volume.

## Recommended settings
- Pool size 120 per node, max wait 3 seconds, leak detection 30 seconds.
